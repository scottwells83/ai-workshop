# Documents

Read the source and preserve factual content and supplied originals. Determine audience, purpose, format, and any user style constraints. Make substantive changes that serve the request; avoid unnecessary decoration. For a revision, save a separately named deliverable unless the user asks to overwrite. Render and inspect the finished document when layout matters. Check headings, page flow, links, and requested content before reporting completion. Use the available document or PDF tools; do not claim visual QA from text inspection alone.
